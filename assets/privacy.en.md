 2. Data we process

 a) Leaderboard data (username + lap times)
If you submit times to the leaderboard, we store:
- Username (chosen by you)
- Lap times
- Associated track/race reference (master data) and minimal metadata needed for display (e.g., entry timestamp, platform/app version if provided)

Purpose: displaying and operating leaderboards, preventing abuse/manipulation, support and issue resolution.

 b) Master data (tracks/races)
We store and process master data such as track and race information.

Purpose: providing core functionality (selection/display/evaluation).

 c) Optional Discord login
If you choose to sign in with Discord, we process (depending on granted scopes) typically:
- Discord user ID (and possibly username/avatar)
- Auth/session data (e.g., token/session identifier)

Purpose: authentication, account linking, and providing logged-in features.

 d) Technical data / server logs (backend on Vercel)
When the apps connect to the backend, technically necessary data may be processed, such as:
- IP address, timestamps, requested endpoints/requests, error logs, technical metadata (as provided)

Purpose: service operation, security, troubleshooting, stability, and abuse prevention.

 e) No analytics / crash reporting in the App Store release
The public App Store releases of LapTime and LapTime Leaderboard do not include additional analytics or crash reporting SDKs.  
(Backend server logs may still apply as described above.)

 f) TestFlight beta (only if you participate in betas)
If you use a TestFlight beta build, crash/usage information and feedback may be shared with the developer as part of the beta testing process (TestFlight builds only).

 3. Legal bases
- Providing the leaderboard feature (upload/display/manage entries): Art. 6(1)(b) GDPR  
- Operation, security, troubleshooting, abuse prevention: Art. 6(1)(f) GDPR

 4. Hosting / recipients (Vercel EU)
The backend is hosted on Vercel in the EU region. Vercel processes data as an infrastructure/hosting provider to deliver the service.

Note: Processing outside the EU/EEA is avoided where possible, but may not be fully excludable in exceptional cases (e.g., technical delivery, security mechanisms, or support processes).

Other recipients:
- Discord, if you use Discord login (independent provider)

 5. Retention
- Leaderboard data (username + lap times): until you delete it / request deletion, or as long as necessary for leaderboard operation.  
- Server logs: e.g., 14 days, then deletion/anonymization unless needed for security.  
- Discord auth/session data: as needed for login/account linking; sessions/tokens as required.

 6. Deletion requests
You can request deletion of your leaderboard entries at any time: privacy@laptime.schubertmarkus.de  
Please include your username and (if available) linking details (e.g., Discord ID).
